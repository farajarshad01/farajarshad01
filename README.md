## About

I build machine learning systems and AI-powered applications, from the data pipeline to the interface people actually use. I care about models that are explainable, pipelines that are reproducible, and tools that solve a real problem.

**What I work on**

- Predictive Modeling with Python and Scikit-learn
- Explainable ML with SHAP
- LLM-powered applications
- Automated, Reproducible ML pipelines with CI/CD
